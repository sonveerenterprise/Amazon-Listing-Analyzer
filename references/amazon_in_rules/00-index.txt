AMAZON.IN LISTING RULES - KNOWLEDGE BASE FOR A LISTING-CHECK SKILL
Built from Seller Central Help pages, read 17 Nov 2026 (amazon.in).
Condensed notes in plain words, with checklists. Re-check the source pages every few months; Amazon changes rules.

CONFLICTS FOUND BETWEEN AMAZON'S OWN PAGES
- Backend search terms limit: Attributes guide = 200 bytes (error 97779); Search optimisation page = "less than 250 bytes". Use 200.
- Numbers: bullet guide says write one to nine as words (except measurements); title guide says use numerals in titles. Both apply to their own field.


SCORING IDEA FOR THE SKILL
1. Compliance (blocks/suppression risk): title rules, banned characters, claims in images/bullets, MAIN image rules
2. Completeness: required + recommended attributes, 7+ images, video, A+ (Premium), Brand Story
3. Discoverability: title front-loads brand + main keyword, item highlights, backend terms, browse node, indexing check
4. Conversion: answers to top buyer questions (Alexa for Shopping suggestions), price vs. competitors, delivery promise, reviews/rating
5. Growth readiness: coupon, sampling/Vine, ads, Bazaar eligibility, experiments when traffic allows
